1. Map: It is used to iterate over an array, and it will return a new array

	syntax: arr_name.map((initial_value,index,array) => {//code})


2. filter: It is used to filter the data based on the condition, and it will return a new array with filtered values.

	syntax: arr_name.filter((initial_value,index,array) => condition)

3. find: It is used to find the value based on the condition, and it will return the value.

	syntax: arr_name.find((initial_value,index,array) => condition)
